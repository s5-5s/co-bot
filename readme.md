# co-bot — локальный симулятор

Запуск из корня проекта: `python3 -m http.server 8000`, затем открыть `http://localhost:8000/`.
`index.html` находится в корне, Three.js загружается из локального `vendor/three.min.js`; внешние CDN не требуются.

* В `js/config.js` находятся масштаб модели, камера, сетка, параметры суставов и IK.
* В `js/scene.js` — существующий цикл рендера и физики, освещение и оси координат.
* Three.js здесь — **предоставленная в исходном архиве локальная кастомная сборка**, не официальный полный дистрибутив npm.
* GLTF содержит только простые PBR-материалы без карт нормалей и шероховатости.

Вид сцены восстановлен под чёрный фон и красную сетку, полноэкранный WebGL-canvas; свет и тени на корпусе усилены. Для реально фотореалистичного вида необходимы качественные материалы модели и полноценный официальный дистрибутив Three.js.
