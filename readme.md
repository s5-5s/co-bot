# co-bot — локальный симулятор

Запуск из корня проекта: `python3 -m http.server 8000`, затем открыть `http://localhost:8000/`.
`index.html` находится в корне, Three.js загружается из локального `vendor/three.min.js`; внешние CDN не требуются.

## Управление TCP

* `TCP BASE` — Cartesian Jog относительно фиксированных осей основания робота.
* `TCP TOOL` — тот же Jog относительно текущих осей инструмента.
* `TCP TARGET` — абсолютная целевая позиция X/Y/Z, выполняемая по кнопке `ок`.

В BASE и TOOL виртуальный XY-джойстик и Z-ползунок являются spring-контролами: после отпускания они возвращаются в нейтраль, а робот остаётся в достигнутом положении.

DualShock/Gamepad API:
* левый стик — X/Y Jog;
* L2/R2 — -Z/+Z Jog;
* правый стик — камера;
* L1/R1 — отдаление/приближение камеры;
* Options — сброс во всех трёх режимах.

## Код

* `js/config.js` — параметры модели, суставов, рабочей зоны, камеры и скорости Jog.
* `js/robot.js` — прямая кинематика и плавное движение суставов с ограничениями скорости и ускорения.
* `js/ik.js` — аналитическая обратная кинематика позиции TCP: J1–J3 решают XYZ, углы J4–J6 сохраняются.
* `js/controller.js` — абсолютная цель, BASE/TOOL Jog и движение к найденным углам.
* `js/gamepad-api.js` — состояние Gamepad API и команды DualShock.
* `js/scene.js` — Three.js, освещение, камера и единый `requestAnimationFrame`-цикл.
* `js/ui.js` — три режима правой панели, виртуальный Jog и телеметрия.
