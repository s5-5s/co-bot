# ко-бот / co-bot

Операторский интерфейс для realtime-модели 6-осевого манипулятора. Визуализация и связь суставов с GLTF построены на локальном модуле OpenSim; приложение не загружает Three.js или другие runtime-зависимости из CDN.

## Запуск

Проект использует ES-модули и загрузку GLTF, поэтому страницу нужно открывать через локальный HTTP-сервер:

```bash
ruby -run -e httpd . -p 4173
```

Затем открыть `http://localhost:4173/html/`.

## Управление

- X/Y/Z задаются в миллиметрах в мировой системе координат.
- «Переместить» рассчитывает IK и сохраняет текущую ориентацию TCP.
- «Домой» возвращает все суставы в нулевую позу.
- Основная модель показывает фактическое положение, красная полупрозрачная pose — рассчитанную командную позу.
- Звенья используют нейтральную бело-серую палитру и PBR-материалы окрашенного/полированного металла с clearcoat-бликами.
- TCP подсвечивается жёлтым во время движения, зелёным при достижении цели и красным при ошибке.

Цель автоматически ограничивается рабочей областью: радиус `66.67–2000 мм`, Y от `−533.33` до `2000 мм`.

## Архитектура

```text
html/index.html              семантическая структура операторского UI
css/                         адаптивное оформление панелей и viewport
js/index.js                  композиция зависимостей и запуск
js/modules/open-sim.js       неизменяемый runtime-бандл OpenSim
js/modules/open-sim.d.ts     справочная декларация API, не используется runtime
js/source/robot-view.js      адаптер публичного API OpenSim
js/source/controller.js      use cases, состояние и motion-loop
js/source/joints.js          конфигурация суставов, лимиты и движение
js/source/ik.js              численный IK без зависимости от Three.js
js/source/math.js            операции над числовыми буферами
js/source/ui.js              DOM-ввод и вывод
```

Контроллер зависит только от контрактов UI, view и solver. В горячем цикле используются фиксированные `Float64Array` и объекты стабильной формы; стрелочные функции оставлены для callback-функций, а вычислительные методы размещены на прототипах.

## Проверки

В проекте нет устанавливаемых npm-зависимостей. Нужен современный Node.js:

```bash
npm test
npm run check
```
